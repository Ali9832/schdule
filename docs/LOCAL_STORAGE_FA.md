# ذخیرهٔ داده‌های اجرای محلی

در اجرای محلی بدون PostgreSQL، داده‌های سرور اکنون در `.local/memory-3001.json` ذخیره می‌شوند. شمارهٔ پورت بخشی از نام فایل است تا اجرای آزمایشی با سرور اصلی مخلوط نشود. پس از راه‌اندازی مجدد همان اطلاعات و شناسه‌ها خوانده می‌شوند.

متغیر `NOVA_LOCAL_STORE` مسیر فایل دیگری را مشخص می‌کند. مقدار `off` ذخیره را برای سرورهای آزمایشی موقت غیرفعال می‌کند. در محیط production یا Vercel این ذخیرهٔ محلی فعال نیست؛ از PostgreSQL استفاده کنید.

تیک‌ها، یادداشت‌ها و ویرایش‌های مستقل بانک آیتم‌ها همچنان در localStorage مرورگر ذخیره می‌شوند؛ تسک‌های متصل در فایل سرور نیز ذخیره می‌شوند. انتقال پروژه به رایانهٔ دیگر به‌تنهایی داده‌های مرورگر را منتقل نمی‌کند.

پوشه‌های `.local` و `backups` حاوی دادهٔ شخصی‌اند و در Git، تصویر Docker و ZIP پروژه قرار نمی‌گیرند. برای پشتیبان‌گیری از داده‌های سرور، هنگام خاموش‌بودن برنامه فایل `.local/memory-3001.json` را جداگانه کپی کنید. فایل Excel مرجع در ZIP موجود است و برای اجرای عادی لازم نیست.
